Ajanta Engine Documentation

Ajanta Studio is engineered for high-performance procedural vector graphics and dynamic motion synthesis. Below is the technical specification of the underlying geometry pipeline, spline evaluation algorithms, and motion keyframe engine.

1. Vector Topology & Path Architecture

Vector paths in Ajanta are represented as directed acyclic geometry graphs consisting of anchor nodes ($P_0, P_n$) and control tangent vectors ($C_1, C_2$). Paths support non-destructive boolean operations (Union, Intersection, Difference, XOR) computed with exact arithmetic precision.

The engine maintains continuity across connected segments, guaranteeing smooth transitions under high magnification without raster aliasing.

2. Parametric Bézier Splines

Cubic Bézier curves are evaluated using Bernstein polynomials across normalized time $t \in [0, 1]$:

B(t) = (1-t)³P₀ + 3(1-t)²t P₁ + 3(1-t)t² P₂ + t³ P₃

Ajanta's curve engine calculates exact arc lengths using Gaussian quadrature numerical integration, ensuring uniform velocity during path-following animation.

3. Ramanujan Mathematical Modifiers

The modifier stack allows artists to apply non-destructive procedural deformations to standard paths:

  • Harmonic Oscillator: Applies sine-wave frequency modulations along the path normal vector.
  • Logarithmic Spiral: Wraps linear splines into equiangular spirals with customizable golden ratio exponents.
  • Modular Sieve: Subdivides and segments paths based on modular arithmetic intervals.

4. Motion Timeline & Keyframe Interpolation

The motion engine supports multi-track keyframing with customizable cubic-bezier easing curves ($x_1, y_1, x_2, y_2$). Spatial motion paths can be edited directly on the canvas with interactive tangent handles.

// Sample Keyframe Definition (.aja) { "property": "path.curvature.g2", "keyframes": [ { "time_ms": 0, "value": 0.0, "easing": "ease-in-out" }, { "time_ms": 1200, "value": 1.45, "easing": [0.42, 0.0, 0.58, 1.0] } ] }

5. GPU Fragment Shaders

Ajanta compiles GLSL fragment shaders directly to Skia / Impeller pipeline shaders. Shaders operate in floating-point linear color space (RGBA16F / RGBA32F) for HDR-ready glow and dispersion effects.

6. Scripting API

Extend Ajanta's core functionality using the embedded Dart / Python scripting engine. Automate batch asset exports, procedural path generators, and parametric typography layouts.
