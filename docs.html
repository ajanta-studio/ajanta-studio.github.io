Ajanta Engine Documentation

Ajanta Studio is engineered for high-performance procedural vector graphics, tactile skeletal animation, and non-destructive motion composition. Below are the technical specifications for Ajanta's core feature pipelines.

1. Easy / Intuitive Marionette Strings Bone Animation

Skeletal Rigging Puppet Physics Inverse Kinematics

Ajanta introduces a natural, strings-based puppet rigging system. Instead of complex, rigid weight-painting pipelines, users attach intuitive Marionette Strings between puppet bones and vector anchor point clusters.

Manipulating a marionette control handle propagates smooth, continuous inverse kinematics through the connected spline segments, enabling expressive character animations and organic deformations without vertex pinching or mesh distortion.

2. Fully Non-Destructive, Fully Animatable Recipes

Parametric Node Stack Live Evaluation Timeline Keyframeable

All operations in Ajanta—Boolean operations, contour offsets, chamfers, bevels, stroke expansions, and transformations—are encapsulated in a procedural Recipe Stack.

Recipes never bake or flatten vector geometry. Crucially, every parameter within a recipe is fully animatable over time. You can keyframe the radius of an offset contour, modulate a boolean cut threshold, or transition non-destructive bevel angles dynamically across the timeline.

// Sample Animatable Recipe Block (.aja) { "recipe": "ContourOffset", "enabled": true, "params": { "radius": { "type": "animated_scalar", "keyframes": [ { "time": 0.0, "value": 2.0 }, { "time": 1.5, "value": 18.5, "easing": "cubic(0.2, 0.8, 0.2, 1.0)" } ] }, "join_type": "round" } }

3. Freeform Gradient Fills

Mesh Interpolation Organic Shading Multi-Point Stops

Ajanta's Freeform Gradient Fill engine allows creators to drop arbitrary color stops anywhere within a 2D vector path. The renderer constructs a dynamic Delaunay triangulation mesh across the geometry, evaluating harmonic coordinates to produce silky, photorealistic gradient blends that adapt in real time as the path deforms.

4. Procedural Properties

Math Expressions Harmonic Oscillators Generative Controllers

Drive any vector property dynamically using mathematical expressions, modular controllers, and harmonic oscillators. Procedural properties can be linked across multiple layers—enabling procedural dash patterns, pulsing scales, or rotational arrays driven by unified mathematical variables.

5. Procedural Material Shaders

GPU Skia / Impeller Fragment GLSL HDR Lighting & Noise

Ajanta embeds custom GPU pixel shaders directly into vector fills and strokes. Render physically plausible materials such as brushed aluminum, iridescent glass, refractive lenses, and procedural Voronoi textures with 120 FPS hardware acceleration.

6. Multi-Track Motion Timeline & Graph Editor

Fine-tune spatial motion trajectories and velocity curves with precision cubic-bezier handles. Seamlessly export complete vector projects to SVG, Lottie, and high-framerate MP4 video formats.
